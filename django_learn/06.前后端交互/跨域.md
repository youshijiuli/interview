# 跨域问题



## 1. 使用中间件解决跨域

- `Middleware.py`

```python
from django.middleware.security import SecurityMiddleware
from django.utils.deprecation import MiddlewareMixin


class MyCors(MiddlewareMixin):

    def process_response(self, request, response):
        response["Access-Control-Allow-Origin"] = "*"
        if request.method == "OPTIONS":
            response["Access-Control-Allow-Methods"] = "PUT, DELETE"
            response["Access-Control-Allow-Headers"] = "content-type"
        return response
```





- `Settings.py`

```python
MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',
    'django.contrib.sessions.middleware.SessionMiddleware',
    'django.middleware.common.CommonMiddleware',
    'django.middleware.csrf.CsrfViewMiddleware',
    'django.contrib.auth.middleware.AuthenticationMiddleware',
    'django.contrib.messages.middleware.MessageMiddleware',
    'django.middleware.clickjacking.XFrameOptionsMiddleware',
    'middlewares.MyCors', # 中间件注册
]
```





## 2. cors组件

#### 作用：

`django-cors-headers` 是 Django 中一个非常有用的第三方应用程序，用于处理跨源资源共享（CORS）问题。当你的 Django 项目作为 API 服务器时，可能会遇到前端应用与后端服务器位于不同域的情况，这时就需要使用 CORS 来允许跨域请求。

#### 功能特点：

1. **跨域请求处理**：允许你在 Django 项目中设置跨域请求的来源，方法和头部，以便前端应用能够安全地访问你的 API。

2. **简化配置**：通过简单的配置，就可以启用 CORS 支持，而无需手动处理 HTTP 头。

3. **灵活性**：提供了许多选项和定制功能，可以根据项目的需求进行调整。

#### 使用方法：

1. **安装 `django-cors-headers`**：

	你可以通过 pip 安装 `django-cors-headers`：

	```
	pip install django-cors-headers
	```

2. **添加到 Django 项目中**：

	在 `settings.py` 中添加 `corsheaders` 到 `INSTALLED_APPS`：

	```python
	INSTALLED_APPS = [
	    # 其他应用...
	    'corsheaders',
	]
	```

3. **配置中间件**：

	在 `settings.py` 中添加 `CorsMiddleware` 到 `MIDDLEWARE`：

	```python
	MIDDLEWARE = [
	    # 其他中间件...
	    'corsheaders.middleware.CorsMiddleware',
	    # 请确保 'django.middleware.common.CommonMiddleware' 在 'corsheaders.middleware.CorsMiddleware' 之前
	]
	```

4. **配置允许的来源**：

  在 `settings.py` 中添加允许的 CORS 来源，例如允许所有来源：

  ```python
  CORS_ALLOWED_ORIGINS = [
      "http://localhost:3000",
      "https://example.com",
  ]
  
  # 3.0以上版本需要加协议，3.0以下不需要--->127.0.0.1:8000
  CORS_ORIGIN_WHITELIST = (
      'http://127.0.0.1:8000',
      'http://127.0.0.1', # 不写端口，默认80
  )
  ```

  或者允许所有来源：

  ```python
  CORS_ALLOW_ALL_ORIGINS = True
  
  
  CORS_ORIGIN_ALLOW_ALL = True
  CORS_ALLOW_CREDENTIALS = True
  ```

  你还可以配置其他选项，例如允许的请求方法、允许的请求头等。

5. **示例代码**：

	下面是一个简单的示例，演示了如何配置 `django-cors-headers`：

	```python
	# settings.py
	
	INSTALLED_APPS = [
	    # 其他应用...
	    'corsheaders',
	]
	
	MIDDLEWARE = [
	    # 其他中间件...
	    'corsheaders.middleware.CorsMiddleware',
	    # 请确保 'django.middleware.common.CommonMiddleware' 在 'corsheaders.middleware.CorsMiddleware' 之前
	]
	
	CORS_ALLOWED_ORIGINS = [
	    "http://localhost:3000",
	    "https://example.com",
	]
	```

#### 使用示例：

假设你有一个 Django API 视图，需要允许来自 `http://localhost:3000` 的跨域请求。你可以这样配置和使用 `django-cors-headers`：

```python
# views.py

from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt

@csrf_exempt
def my_api_view(request):
    if request.method == 'GET':
        data = {
            'message': 'Hello from Django API!'
        }
        return JsonResponse(data)

# settings.py

INSTALLED_APPS = [
    # 其他应用...
    'corsheaders',
]

MIDDLEWARE = [
    # 其他中间件...
    'corsheaders.middleware.CorsMiddleware',
    # 请确保 'django.middleware.common.CommonMiddleware' 在 'corsheaders.middleware.CorsMiddleware' 之前
]

CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",
]

# urls.py

from django.urls import path
from .views import my_api_view

urlpatterns = [
    path('my-api/', my_api_view, name='my_api'),
]
```

在这个示例中，我们定义了一个简单的 API 视图 `my_api_view`，它返回一个包含消息的 JSON 响应。我们使用 `@csrf_exempt` 来取消 CSRF 保护，以简化示例。

在 `settings.py` 中，我们将 `corsheaders` 添加到 `INSTALLED_APPS` 和 `MIDDLEWARE` 中，并配置了允许的 CORS 来源为 `http://localhost:3000`。

最后，在项目的 `urls.py` 中，我们将 `my_api_view` 视图映射到 `/my-api/` 路径。

现在，前端应用（例如位于 `http://localhost:3000`）就可以安全地从该 API 获取数据了，因为我们通过 `django-cors-headers` 允许了跨域请求。

- 其他配置

```
 
CORS_ORIGIN_ALLOW_ALL = True
# 实际请求所允许的请求方式列表。默认为：
CORS_ALLOW_METHODS = (
    'DELETE',
    'GET',
    'OPTIONS',
    'PATCH',
    'POST',
    'PUT',
    'VIEW',
)
# 发出实际请求时可以使用的非标准HTTP标头的列表。默认为:
CORS_ALLOW_HEADERS = (
    'XMLHttpRequest',
    'X_FILENAME',
    'accept-encoding',
    'authorization',
    'content-type',
    'dnt',
    'origin',
    'user-agent',
    'x-csrftoken',
    'x-requested-with',
    'Pragma',
)
```





- 参数详解

```python
# 跨域请求时，是否运行携带cookie，默认为False
CORS_ALLOW_CREDENTIALS 
 
 
CORS_ORIGIN_ALLOW_ALL
# 如果为True，将不使用白名单，并且将接受所有来源。默认为False。
```
