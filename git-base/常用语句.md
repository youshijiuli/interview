# 常用语句

## 1、提交文件

```Plain Text
$ git add pack_name$ git add .                *# 添加所有文件*$ git commit -m "备注"$ git push origin master
```

## 2、克隆，拉取更新

```Plain Text
$ git clone https://github.com/zehuilu/CBBA-Python.git        *# 地址*$ git pull origin master 
```

## 3、初始化仓库

```Plain Text
$ git init
```

## 4、查看提交历史

```Plain Text
$ git log 
//以简洁的方式查看
$ git log --oneline$ git log --author yourname                *# 通过作者搜索*$ git log --grep keywords                *# 通过提交关键字搜索*
//按q键 退出当前窗口
```

## 5、回退版本

```Plain Text
$ git reset HEAD^            *# 回退所有内容到上一个版本  *$ git reset HEAD^ hello.php  *# 回退 hello.php 文件的版本到上一个版本  *$ git  reset  052e           *# 回退到指定版本*
```

HEAD 说明：

- HEAD 表示当前版本

- HEAD^ 上一个版本

- HEAD^^ 上上一个版本

- HEAD^^^ 上上上一个版本

可以使用 ～数字表示

- HEAD~0 表示当前版本

- HEAD~1 上一个版本

- HEAD^2 上上一个版本

- HEAD^3 上上上一个版本

## 6、切换分支

```Plain Text
# 查看所有分支$ git branch
# 以下命令允许你从当前分支切换到指定的分支 <branch-name>:$ git checkout <branch-name>
# 切换到主分支$ git checkout master 
# 创建新分支并切换# 例如创建一个名为 feature-branch 的新分支并切换到它$ git checkout -b feature-branch$ git merge        branchname         *# 将分支合并到主分支*
```

## 7、删除指令

```Plain Text
# 以下实例从暂存区和工作区中删除 runoob.txt 文件：$ git rm -f runoob.txt 
```

## 8、配置

```Plain Text
# 显示当前的 git 配置信息：$ git config --list
# 设置提交代码时的用户信息：$ git config --global user.name "runoob"$ git config --global user.email test@runoob.com
```

## 9、Git 全局设置:

```Plain Text
$ git config --global user.name "鲁建明-star"$ git config --global user.email "10330222+lu-jianming-star@user.noreply.gitee.com"
```

## 10、创建 git 仓库:

```Plain Text
$ mkdir blue_bridge$ cd blue_bridge$ git init $ touch README.md$ git remote add origin https://gitee.com/lu-jianming-star/blue_bridge.git$ git add README.md$ git commit -m "first commit"$ git push -u origin "master"
```

已有仓库?

```Plain Text
$ cd existing_git_repo$ git remote show origin *# 查看当前连接仓库*$ git remote add origin https://gitee.com/lu-jianming-star/blue_bridge.git        *# 连接到远程仓库*$ git push -u origin "master"
```
