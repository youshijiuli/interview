# 数据库操作


数据库连接`flask-SQLAlchemy`的使用

1.初始化和设置数据库配置信息

使用`flask_sqlalchemy`中的`SQLAlchemy`进行初始化：

```python
from flask_sqlalchemy imprt SQLAlchemy
app = Flask(__name__)
db = SQLAlchemy(app)
```



2.设置配置信息：在`config.py`文件中添加以下配置信息：

配置数据库连接

```python
DIALECT = 'postgresql'
DRIVER = ''
USERNAME = ‘’
PASSWORD = ''
HOST = ‘’
PORT = ‘’
DATABASE = ‘’

SQLALCHEMY_DATABASE_URI = "{}://{}:{}@{}:{}/{}".format(DIALECT, USERNAME, PASSWORD, HOST, PORT, DATABASE)

SQLALCHEMY_TRACK_MODIFICATIONS = False
```



除了`mysql`之外还可以使用文件数据库，

# 文件数据库

方法：

配置数据库

```python
from flask import Flask

basedir = os.path.abspath(os.path.dirname(__file__))　　# 获取当前文件的绝对路径

app = Flask(__name__)

# 拼接数据库的ＵＲＬ路径
# os.path.join　把basedir和data.sqlite的路径拼接起来#
# data.sqlite为数据库文件，若该文件夹下没有这个文件会自动创建

app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///'+ os.path.join(basedir,'data.sqlite')

# 配置这个键之后，每次请求结束之后都会提交数据库的变动

app.config['SQLALCHEMY_COMMIT_ON_TEARDOWN'] = True

db = SQLAlchemy(app)
```





3.在主`app.py`文件中，添加配置文件

```python
import config
app.config.from_object(config)
```



4.做测试，看有没有问题

```python
db.creat_all()
```

若没有报错，说明配置没有问题；若报错，修改
