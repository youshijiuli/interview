# 块和继承

​		一般我们的网站虽然页面多，但是很多部分是重用的，比如页首，页脚，导航栏之类的。对于每个页面，都要写这样的代码，很麻烦。Flask的jinja2模版支持模版继承功能，省去了些重复代码。

## 一、块（block）

**父模版**

首先，你需要创建一个基础模板，通常包含一些公共的部分如头部、主体容器和脚部。在这个模板中，你可以定义一个或多个块（block），这些块将在子模板中被覆盖或扩展。

```html
<body>
    你好，template1
    {% block template1 %}
    {% endblock %}
    
    你好，template2
    {% block template2 %}
    {% endblock %}
    
    你好，template
    {% block template %}
    {% endblock %}
</body>
```

**子模版**

接着，你可以创建一个子模板来继承基础模板，并且覆盖其中的一个或多个块。

在子模板中，使用 `{% extends "template_name" %}` 标签来指明要继承哪个基础模板

```html
{% extends "he.html" %}


{% block template %}
{{ super() }}  
<h1>yuan</h1>
{% endblock %}


{% block template1 %}
<h1>alex</h1>
{% endblock %}
```

​		在子模板中，使用 `{% block name %}...{% endblock %}` 来定义新的块内容，如果基础模板已经定义了相同的块名，那么这个块就会被覆盖。当一个子模板覆盖了一个父模板中的块时，如果希望保留父模板中该块的内容，就需要使用 `{{ super() }}`。

## 二、导入（include)

​		这个标签相当于是直接将指定的模版中的代码复制粘贴到当前的位置。`include`标签，如果想要使用父模版中的变量，直接用就可以了。`include`的路径，也是跟`import`一样，直接从`template`根目录下去找，不要以相对路径去找。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>SXT</title>
</head>
<body>
    <!--通过include 引入头部log信息-->
    {% include "common/head.html" %}
    
    
    <div>
        这是首页内容
        {{ major }}
    </div>
    <hr>
    
    
    <!--通过include 引入底部版权信息-->
    {% include "common/footer.html" %}
</body>
</html>

```
