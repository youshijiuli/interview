# 一、反向解析

​		一般我们通过一个URL就可以执行到某一个函数。如果反过来，我们知道一个函数，怎么去获取这个URL呢？Flask中提供了url_for函数帮我们实现这个功能。

​		`url_for() `： 函数接收两个及以上的参数，他接受函数名作为第一个参数，接收对应的URL规则的命名参数，若果还出现其他的参数，则会添加到URL的后面作为查询参数。

​		比如：

```python
@app.route('/post/list/<page>')
def my_list(page):
    return 'my list'

@app.route('/')
def hello_world():
    # 反向解析出url：/post/my_list/2?num=8
    path = url_for('my_list', page=2, num=8)
    print(type(path))  # 其实是一个字符串
    return path
```

注意`url_for`函数还会转义一些特殊字符和unicode字符集。比如中文或者/

# 二、重定向

如何在不同的场景返回不同的响应信息？

Flask中的重定向使用的是`redirect()`函数实现。

```python
from flask import Flask, redirect


@app.route('/demo1')
def demo1():
	# redirect函数传入一个url路由路径，就可以实现重定向
	return redirect('https://www.baidu.com')

@app.route('/demo2')
def demo2()
	# 还可以配合url_for使用
    return redirect(url_for('demo1'))  # 重定向到demo1视图函数中
```
