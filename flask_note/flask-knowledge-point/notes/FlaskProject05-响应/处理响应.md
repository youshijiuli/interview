# Flask中如何处理响应

## 一、返回字符串响应

可以直接在视图函数中return返回一个字符串。

```python
@app.route('/')
def index():
    return "hello world"
```



## 二、返回JSON响应

Flask 可以方便地返回 JSON 数据，只需要导入 `jsonify` 函数即可。

```python
from flask import jsonify

@app.route('/')
def demo():
    json_dict = {
        'user_id': 1,
        'user_name': 'wx'
    }
    return jsonify(json_dict)

```

`jsonify`函数会把Python的字典序列化为一个JSON响应对象返回出去。



## 三、自定义响应

### （1）元组方式

可以返回一个元组，这样的元组必须是(response, status, headers)的形式，且至少包含一个元素。status值会覆盖状态代码，headers可以是一个列表或者字典，作为额外的信息响应头。

```python
@app.route('/')
def demo():
    return "状态码为 666", 666, {'my_param', 'python'}
```

### （2）`make_response`方式

Flask提供了`make_response`函数，可以用来将任何可迭代对象转换成一个响应对象。

```python
# make_response函数里面也是按顺序传入参数(reponse, status, headers)
@app.route('/demo')
def demo():
    response = make_response('make_response测试', 200, {'X-Custom-Header': 'Custom Value'})
    return response


# 还可以先用make_response函数创建出reponse对象后，再给属性
@app.route('/demo')
def demo():
    response = make_response('make_response测试')
    response.headers['X-Custom-Header'] = 'Custom Value'
    response.status = '404 not found'
    
    return response
```

## 四、返回模版响应

使用`render_template`方法渲染模版并返回

例如，新建一个模版index.html

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>标题</title>
</head>
<body>
    我的模板html内容
    <br/>{{ my_str }}
    <br/>{{ my_int }}
</body>
</html>
```

后端视图

```python
from flask import render_template

@app.route('/')
def index():
    # render_template函数的第一个参数是模版的路径，后续参数是传入模版的变量参数
    username = 'wx'
    age = 18
    return render_template('index.html', age=age, username=username)
```
