# 异常处理

## 一、HTTP异常主动抛出

`abort(code)`方法：抛出一个给定状态码的HTTPException或者指定响应 ，如果想要用一个页面未找到来终止请求，可以 调用abort(404)。该方法的参数是code即HTTP的错误状态码

```python
abort(404)
```

补充一下restful接口状态码

| 类别            | 描述                                         |
| :-------------- | :------------------------------------------- |
| 1xx：信息       | 通信传输协议信息                             |
| 2xx：成功       | 表示客户端的请求已成功接受                   |
| 3xx：重定向     | 表示客户端必须执行一些其他操作才能完成其请求 |
| 4xx：客户端错误 | 此类错误状态码指向客户端                     |
| 5xx：服务器错误 | 服务器负责这些错误状态码                     |

- 200 请求成功
  - 当请求成功，但又无法用201,202,204区分的时候，一般就使用200表示OK，请求成功

- 301 永久重定向

  - 一般用于比如网址永久修改

- 302 临时重定向

  - 一般用于临时跳转 

- 400 非法请求

  - 一般来说是入参填错了，应该返回400

- 401 认证失败

  - 一般是密码或者token等错误

- 403 禁止访问

  - 一般是当前角色没有权限操作

- 404 页面未找到

  - 这个是最常见的，url填错了

- 405 请求方法不允许

  - 这个用的不是太多，一般是测试时候方法用错了，比如服务端只支持post方法，客户端使用get方法请求，则应返回405

- 500 服务器错误

  - 一般是指服务端代码中未知的错误，一般来说500为严重错误，即代码发生了不可预知的错误

- 503 服务器无法处理

  - 一般是指此时服务器异常了，如服务挂了或者服务尚未启动完成等

  

## 二、捕获异常

- `errorhandler`

  - **功能**：这是一个装饰器，可以装饰一个错误处理函数，当程序抛出指定错误状态码的时候，就会调用该装饰器所装饰的方法

  - **参数**：code_or_exception 可以是一个错误状态码，或是指定的异常

```python
@app.errorhandler(500)
def internal_server_error(e):
    return '服务器搬家了'



@app.errorhandler(ZeroDivisionError)
	return '除数不能为0'
```
