# Flask框架知识点快速上手

#### 介绍
Flask框架知识点快速上手仓库包含三个内容：
1. Flask入门（视图、模版、路由）
2. Flask模型类（模型、数据库交互）
3. Flask高级（插件、静态文件、前后断分离）

#### 文档架构
1. source_code存放学习案例代码
1. notes存放知识点笔记


#### 安装教程

1.  pip install flask

#### 使用说明

1.  以Flask2Project开头的文件夹就是一个项目文件，用pycharm打开。
1.  或者进入Flask2Project文件中，打开cmd运行python app.py命令
