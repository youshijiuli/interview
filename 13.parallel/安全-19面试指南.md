## 17 安全相关面试题

### Q79: 常见的 Web 安全攻击及防范？

| 攻击类型 | 说明 | 防护措施 |
|---------|------|---------|
| **XSS（跨站脚本）** | 恶意脚本注入页面执行 | 输入转义、输出编码、CSP 策略 |
| **CSRF（跨站请求伪造）** | 恶意站点诱导用户执行操作 | CSRF Token、Referer 校验 |
| **SQL 注入** | 恶意 SQL 拼接 | ORM 参数化查询、输入校验 |
| **点击劫持** | 透明 iframe 诱导点击 | X-Frame-Options 头 |
| **DDoS** | 分布式拒绝服务 | CDN、WAF、限流 |
| **文件上传漏洞** | 上传恶意文件 | 限制文件类型、大小、重命名 |

**Django 中已内置的防护：**
- XSS：模板自动转义 HTML
- CSRF：`{% csrf_token %}` 中间件
- SQL 注入：ORM 自动参数化
- 点击劫持：`XFrameOptionsMiddleware`
