# 模块使用

## struct模块

在 Python 中，`struct` 模块主要用于对 Python 数据和 C 语言结构体之间进行二进制数据的转换操作。下面为你详细介绍该模块的使用方法。

### 1. 核心函数

- **`pack(fmt, v1, v2, ...)`**：按照给定的格式 `fmt`，把数据封装成二进制字符串。
- **`unpack(fmt, buffer)`**：依据格式 `fmt`，从二进制字符串 `buffer` 里解析出数据，结果以元组形式呈现。
- **`calcsize(fmt)`**：计算某种格式 `fmt` 所占用的字节数。

### 2. 格式字符

格式字符代表了 C 语言里的数据类型，以下是常见的格式字符及其含义：



| 格式字符 | C 语言类型     | Python 类型 | 字节数 |
| -------- | -------------- | ----------- | ------ |
| `b`      | signed char    | integer     | 1      |
| `B`      | unsigned char  | integer     | 1      |
| `h`      | short          | integer     | 2      |
| `H`      | unsigned short | integer     | 2      |
| `i`      | int            | integer     | 4      |
| `I`      | unsigned int   | integer     | 4      |
| `f`      | float          | float       | 4      |
| `d`      | double         | float       | 8      |
| `s`      | char[]         | bytes       | -      |

### 3. 字节序标记

字节序标记用于表明数据的存储方式，具体如下：



| 标记 | 字节序             |
| ---- | ------------------ |
| `@`  | 本机字节序         |
| `=`  | 标准字节序         |
| `<`  | 小端字节序         |
| `>`  | 大端字节序         |
| `!`  | 网络字节序（大端） |

### 4. 基础示例

下面是一些基础操作的示例：

```python
import struct

# 打包数据
packed = struct.pack('>Iff', 123456789, 3.14159, 2.71828)
print(packed)  # 输出：b'\x07[\xcd\x15@\t!\xf9!\x10\xfe@'

# 解包数据
unpacked = struct.unpack('>Iff', packed)
print(unpacked)  # 输出：(123456789, 3.141590118408203, 2.7182800773620605)

# 计算格式占用的字节数
size = struct.calcsize('>Iff')
print(size)  # 输出：12（4 字节 + 4 字节 + 4 字节）
```

### 5. 处理字符串

在处理字符串时，需要特别注意：

```python
import struct

# 打包字符串（需要指定长度）
s = b"Hello"
packed = struct.pack('5s', s)  # 5s 表示长度为 5 的字符串
print(packed)  # 输出：b'Hello'

# 解包字符串
unpacked = struct.unpack('5s', packed)
print(unpacked)  # 输出：(b'Hello',)

# 填充字符
packed_padded = struct.pack('5s3x', s)  # 3x 表示 3 个填充字节
print(packed_padded)  # 输出：b'Hello\x00\x00\x00'
```

### 6. 实际应用场景

#### 6.1 网络编程

在网络编程中，`struct` 模块可用于构建网络协议包：

```python
import struct
import socket

# 构建一个简单的网络数据包
def create_packet(command, data):
    header = struct.pack('!BI', command, len(data))
    return header + data

# 解析网络数据包
def parse_packet(buffer):
    header = buffer[:5]  # 假设头部长度为 5 字节
    command, length = struct.unpack('!BI', header)
    data = buffer[5:5+length]
    return command, data

# 使用示例
packet = create_packet(0x01, b"Hello, World!")
cmd, payload = parse_packet(packet)
print(f"Command: {cmd}, Payload: {payload}")
```

#### 6.2 文件操作

在文件操作中，可用于解析二进制文件：

```python
import struct

# 读取二进制文件（例如图像文件的头部）
with open('image.bin', 'rb') as f:
    header = f.read(12)  # 假设头部为 12 字节
    width, height, depth = struct.unpack('>III', header)
    print(f"Width: {width}, Height: {height}, Depth: {depth}")
```

### 7. 注意要点

- 格式字符串必须准确无误，不然会引发 `struct.error` 异常。
- 处理字符串时，要留意字符串的长度，必要时进行填充。
- 进行网络通信时，建议采用网络字节序（`!`）。
- 解包操作返回的是元组，即便只有一个值也是如此。

### 8. 进阶用法

可以借助 `namedtuple` 让解包结果更具可读性：

```python
from collections import namedtuple

# 创建一个命名元组来表示解包结果
Header = namedtuple('Header', ['command', 'length'])

def parse_packet(buffer):
    header = buffer[:5]
    cmd, length = struct.unpack('!BI', header)
    return Header(cmd, length), buffer[5:5+length]

# 使用示例
packet = create_packet(0x01, b"Hello")
header, payload = parse_packet(packet)
print(f"Command: {header.command}, Length: {header.length}")
```





## gevent模块

gevent 是一个基于协程（greenlet）的 Python 网络库，通过轻量级的协程（greenlet）和非阻塞 I/O 实现高效并发。下面为你详细介绍该模块的使用方法。

### 1. 核心概念

- **协程（greenlet）**：轻量级的执行单元，由用户控制调度，而非操作系统。
- **事件循环（Event Loop）**：gevent 的核心，负责监听 I/O 事件并调度协程。
- **猴子补丁（Monkey Patching）**：修改标准库使其支持非阻塞 I/O。

import gevent

def task(n):
    for i in range(n):

### 4. 同步原语

#### 4.1 锁（Lock）

python



运行









```python
import gevent
from gevent.lock import BoundedSemaphore

semaphore = BoundedSemaphore(1)  # 限制同时访问的协程数量为 1

def worker(n):
    semaphore.acquire()
    try:
        print(f"Worker {n} acquired the lock")
        gevent.sleep(1)
    finally:
        semaphore.release()
        print(f"Worker {n} released the lock")

gevent.joinall([gevent.spawn(worker, i) for i in range(3)])
```

运行









```python
import gevent
from gevent.event import Event

evt = Event()

def setter():
    print("Setter: Waiting a few seconds...")
    gevent.sleep(3)
    print("Setter: Notifying listeners")
    evt.set()

def waiter():
    print("Waiter: Waiting for event...")
    evt.wait()  # 阻塞直到事件被设置
    print("Waiter: Event received, continuing")

gevent.joinall([gevent.spawn(setter), gevent.spawn(waiter)])
```

### 7. 高级特性

#### 7.1 协程池（Pool）

限制并发协程的数量：

```python
import gevent
from gevent.pool import Pool

pool = Pool(2)  # 最多同时运行 2 个协程

def task(n):
    print(f"Processing task {n}")
    gevent.sleep(1)
    return n

results = []
for i in range(5):
    results.append(pool.spawn(task, i))

gevent.joinall(results)
print([r.value for r in results])  # 获取结果
```

#### 7.2 异步 DNS 解析

```python
import gevent
from gevent import monkey; monkey.patch_all()
import socket

def resolve(host):
    ip = socket.gethostbyname(host)
    print(f"{host} -> {ip}")
    return ip

hosts = ['google.com', 'github.com', 'python.org']
jobs = [gevent.spawn(resolve, h) for h in hosts]
gevent.joinall(jobs)
```

### 8. 最佳实践

1. **尽早打补丁**：在程序入口调用 `monkey.patch_all()`。
2. **避免阻塞操作**：所有 I/O 操作都应通过 gevent 提供的接口进行。
3. **限制并发数**：使用协程池（Pool）防止资源耗尽。
4. **异常处理**：为长时间运行的协程设置超时。
5. **调试工具**：使用 `gevent.util.wrap_errors` 捕获协程异常。

## socketserver

`socketserver` 是 Python 标准库中用于简化网络服务器编程的模块，它提供了多种服务器类，支持同步、异步和多线程 / 多进程处理请求。下面为你详细介绍该模块的使用方法。

### 1. 核心组件

- 服务器类

  ：负责监听连接并分配处理程序。

  - `TCPServer`：基于 TCP 协议的服务器。
  - `UDPServer`：基于 UDP 协议的服务器。
  - `UnixStreamServer`/`UnixDatagramServer`：基于 Unix 域套接字的服务器。

- 请求处理类

  ：负责处理客户端请求。

  - `BaseRequestHandler`：所有请求处理程序的基类。
  - `StreamRequestHandler`：用于 TCP 连接的处理程序。
  - `DatagramRequestHandler`：用于 UDP 连接的处理程序。

### 2. 基本架构

`socketserver` 采用 **Mixin 类** 和 **基类** 组合的方式构建服务器：



- `ForkingMixIn`：多进程处理请求。
- `ThreadingMixIn`：多线程处理请求。
- `BaseServer`：服务器基类。
- `TCPServer`/`UDPServer`：具体实现类。

### 3. 简单 TCP 服务器示例

python



运行









```python
import socketserver

class MyTCPHandler(socketserver.BaseRequestHandler):
    """处理客户端连接的请求处理类"""
    def handle(self):
        # self.request 是客户端的 socket 对象
        self.data = self.request.recv(1024).strip()
        print(f"来自 {self.client_address} 的数据: {self.data}")
        # 回显数据给客户端
        self.request.sendall(self.data.upper())

if __name__ == "__main__":
    HOST, PORT = "localhost", 9999
    # 创建 TCP 服务器实例
    with socketserver.TCPServer((HOST, PORT), MyTCPHandler) as server:
        print(f"服务器启动在 {HOST}:{PORT}")
        # 启动服务器，一直运行直到手动中断（Ctrl+C）
        server.serve_forever()
```

### 6. 服务器生命周期管理

#### 6.1 处理单个请求

python



运行

import socketserver
import os

class FileHandler(socketserver.StreamRequestHandler):
    def handle(self):
        filename = self.rfile.readline().strip().decode()
        if os.path.exists(filename) and os.path.isfile(filename):
            with open(filename, 'rb') as f:
                self.wfile.write(b"OK\n")

if __name__ == "__main__":

class ProtocolHandler(socketserver.StreamRequestHandler):
    def handle(self):
        # 解析自定义协议头
        header = self.rfile.read(4)
        if header != b'MAGIC':
            return
        
        length = int.from_bytes(self.rfile.read(4), 'big')
        data = self.rfile.read(length)
        
        # 处理数据
        response = self.process_data(data)
        
        # 发送响应
        self.wfile.write(b'MAGIC')
        self.wfile.write(len(response).to_bytes(4, 'big'))
        self.wfile.write(response)

### 8. 注意事项

1. 单线程 vs 多线程 / 多进程

   ：

   - 标准 `TCPServer` 是单线程的，一次只能处理一个请求。
   - 使用 `ThreadingMixIn` 或 `ForkingMixIn` 可以实现并发处理。

2. 资源管理

   ：

   - 多线程服务器需注意线程安全问题。
   - 多进程服务器需注意进程间通信和资源共享问题。

3. 错误处理

   ：

   - 在 `handle()` 方法中捕获异常，避免单个请求处理失败导致整个服务器崩溃。

4. 性能考虑

   ：

   - 对于高并发场景，考虑使用 `asyncio` 或第三方库（如 `gevent`）。
